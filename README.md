# optimize-prompt

A Claude Code mod: an Optimize prompt button above the prompt box. Haiku rewrites your draft in place.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install optimize-prompt --marketplace kelokchan/optimize-prompt
```

Answer `y` to add the marketplace, then pick a scope (user scope is first; press Enter).

From a shell:

```
claude plugin install optimize-prompt --marketplace kelokchan/optimize-prompt
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `kelokchan/optimize-prompt`, then Add plugin.
